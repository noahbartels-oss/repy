# PSN Short-Name Checker & Sniping Bot

A command-line tool that finds short, **valuable PlayStation Network (PSN)
online IDs** that are currently free. Instead of blindly brute-forcing all
456,976 four-letter combinations, it targets the names actually worth having —
pronounceable names, real words, and brandable patterns — and **checks the
highest-scored names first**.

## How it works

For each candidate name the tool asks PSN's universal search whether a profile
with that exact online ID exists:

- **No profile found** → reported as `available` (written to `available.txt`).
- **Exact profile found** → `taken`.

Candidates are generated by one of four modes and, for the targeted modes,
ranked by a **brand score** (real words, pronounceability, premium letters like
x/z/v/j, ending in a vowel, all-distinct characters) so the best names are
checked first.

> ⚠️ **Important caveats**
> - "Available" means *no public profile exists*. PSN can still **reserve**,
>   **temporarily hold** (recently deleted), or **ban** a name — so this is a
>   strong hint, not a guarantee that you can actually register it.
> - Automated querying and reselling online IDs may violate the
>   [PlayStation Network Terms of Service](https://www.playstation.com/legal/psn-terms-of-service/).
>   Keep the delay reasonable and understand the risk to your account. You are
>   responsible for how you use this.

## Setup

```bash
npm install
```

### Get your NPSSO token

The tool authenticates as your PSN account:

1. Log in to <https://www.playstation.com> in your browser.
2. In the same browser, open <https://ca.account.sony.com/api/v1/ssocookie>.
3. Copy the 64-character token from `{"npsso":"<token>"}`.

Provide it in **one** of these ways:

```bash
export NPSSO="your-64-character-token"   # environment variable
# or
echo "your-64-character-token" > npsso.txt   # file (git-ignored)
```

The NPSSO is exchanged for access/refresh tokens cached in `.tokens.json`, so
you normally only provide it once.

## Modes

| Mode          | Flag           | What it generates                                   |
| ------------- | -------------- | --------------------------------------------------- |
| **Brandable** | `--brandable`  | Curated pronounceable patterns (default mode)       |
| **Pattern**   | `--pattern`    | Your own templates, e.g. `CVCV`, `CVCD`             |
| **Words**     | `--words`      | Real dictionary words of the chosen length          |
| **Brute**     | `--brute`      | Every combination of a character set (huge)         |

### Pattern symbols

Templates are built from these letter classes:

| Symbol | Meaning      | Characters              |
| ------ | ------------ | ----------------------- |
| `C`    | consonant    | `bcdfghjklmnpqrstvwxz`  |
| `V`    | vowel        | `aeiou`                 |
| `L`    | any letter   | `a-z`                   |
| `D`    | digit        | `0-9`                   |
| `A`    | alphanumeric | `a-z0-9`                |

`CVCV` produces pronounceable names like `nexo`, `lumi`, `zaro`. `CVCD` gives
names ending in a number like `zar7`.

## Usage

```bash
# Best 4-letter brandable names, most valuable first (default)
node index.js

# Only the 200 most valuable candidates
node index.js --brandable --top 200

# All consonant-vowel-consonant-vowel names
node index.js --pattern CVCV

# Mix patterns, including digits
node index.js --pattern CVCV,CVCD,CVVC

# Real 4-letter dictionary words
node index.js --words

# Real 3-letter words
node index.js --words --length 3

# Brute force a-z plus digits (456k+ names — slow!)
node index.js --brute --alnum

# Go slower, or stop after 500 checks this run
node index.js --delay 2000 --limit 500

# Start over from scratch for the current config
node index.js --reset
```

Run `node index.js --help` for the full list.

### Output

- `available.txt` — names that look free (appended to).
- `.progress.json` — resume position for the current config.
- `.tokens.json` — cached auth tokens.

All of these are git-ignored. The bundled word list lives in `data/words.txt`.

## Notes on scale

- `CVCV` is only 10,000 names; `--brandable` ~30,000; 4-letter words ~7,200 —
  all very manageable. At a 1.3s delay, 10,000 names is roughly 3.6 hours.
- `--brute` over all 4-letter letters+digits is 1.6M+ combinations (days).
  Prefer the targeted modes, or use `--limit` and `--top`.
- The tool resumes after stopping (Ctrl+C), so you can run it in chunks.
- Keep the delay reasonable — aggressive querying risks rate-limiting or your
  account being flagged.
